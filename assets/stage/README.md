# Stage effects source

`effects.png` was generated with ChatGPT for this project at the owner's request.
It is an independent reusable effects sheet, not a replacement for character art:
four frames each of fireworks, sparkles, confetti and smoke in a 4×4 grid.
The firmware uses a 32×32, eight-colour compact atlas generated by
`python3 tools/stagefx_pack.py`. Transparency is thresholded before quantization.
Do not overwrite the source when changing packing parameters.

Assets remain separate from the code licence under `assets/NOTICE.md`.
No additional third-party character, image bank or recording was used.
